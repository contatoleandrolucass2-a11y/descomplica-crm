# Sons de notificação do DESCOMPLICA LEAD

Áudios exportados diretamente do React Bits Sound Lab em 31/10/2026, utilizando os presets indicados pelo usuário:

- `reactbits-lantern.wav`: https://reactbits.dev/tools/sound-lab#sound=lantern — recebimento de lead.
- `reactbits-shake.wav`: https://reactbits.dev/tools/sound-lab#sound=shake — entrada do lead no Bolsão.

Exportação WAV PCM, 16 bits, 44,1 kHz, estéreo. Os ajustes de timbre, duração, efeitos e volume da ferramenta foram mantidos nos valores padrão. A aplicação ajusta apenas o ganho de reprodução: Lantern em 1,5 e Shake em 0,45, preservando o aviso de novo lead mais forte.

Autoria dos presets: React Bits / David Haz. Fonte do projeto: https://github.com/DavidHDev/react-bits. Os arquivos são servidos localmente; a reprodução não depende de chamadas ao React Bits.

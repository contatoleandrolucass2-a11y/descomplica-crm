# Matriz de rastreabilidade da especificação

Data de corte: 2026-08-11.

Esta matriz relaciona a especificação consolidada, o mandato de fechamento
funcional e as 21 páginas protegidas do catálogo. A referência viva orienta a
composição visual, mas não é fonte de dados, fórmula, política ou autorização.

## Convenções

- **Concluído:** implementação e evidência já existentes no SHA-base.
- **Implementado localmente:** código presente neste incremento; a suíte e as
  evidências devem ser regeneradas no SHA final.
- **Parcial:** existe uma entrega segura, mas ainda falta requisito
  determinístico ou evidência final.
- **Bloqueado:** depende de política, owner, credencial ou autorização externa.
- **Indisponível:** não existe fonte segura; a interface deve declarar a
  ausência, nunca substituir por zero ou dado fictício.

Nenhuma referência a uma captura anterior comprova o novo SHA. Toda linha
alterada neste incremento está marcada como **a regenerar no SHA final**.

## Regra de fechamento

Esta matriz só pode ser marcada como evidência do release quando o SHA final
estiver limpo e todas as referências “a regenerar” forem substituídas por
resultados produzidos nesse SHA. Um teste verde local ou uma captura de
homologação não promove flag, política, mapping, grant ou migration remota.
